# Bike Sharing Demand Analysis 
## Project Overview 

This project investigates the relationship of the factors associates with hourly bike rental demand using the UCI Bike Sharind Dataset

## Research Question

1) How does temperatue influence hourly rental demand?

2) Are rentals higher during particular time of the day?

3) How can weather affect rental counts?

4) Can our models reliably predict future hourly rental counts?


## Methods 
- Exploratory Data Analysis 
- Data Visualisation 
- Linear Regression 
- Poisson Regression 
- Negative Binomial Regression

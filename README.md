# Bike Sharing Demand Analysis 
## Project Overview 

This project investigates the relationship of the factors associated with hourly bike rental demand using the UCI Bike Sharing Dataset

## Research Question

1) How does temperatue influence hourly rental demand?

2) Are rentals higher during particular times of the day?

3) How can weather affect rental counts?

4) Can our models reliably predict future hourly rental counts?


## Methods 
- Exploratory Data Analysis s
- Data Visualisation 
- Linear Regression 
- Poisson Regression 
- Negative Binomial Regression
